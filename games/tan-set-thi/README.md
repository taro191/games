# ท่านเศรษฐี — เกมเศรษฐีออนไลน์

เกมเศรษฐีบนมือถือ เล่นคนเดียว/เครื่องเดียวหลายคน/ออนไลน์ มีโหมดพิเศษ "เศรษฐี 6 ภาค" ที่ให้เรียนรู้จุดเด่นของ 6 จังหวัด

## ไฟล์ในชุดนี้
| ไฟล์ | หน้าที่ |
|---|---|
| `tan-set-thi.html` | ตัวเกมทั้งหมด (หน้าเว็บไฟล์เดียว) |
| `server.js` | เซิร์ฟเวอร์: ให้บริการหน้าเกม ล็อกอิน/สมัคร ห้องออนไลน์ เก็บโปรไฟล์ และเข้าสู่ระบบผ่านระบบภายนอก |
| `.env.example` | ตัวอย่างค่าตั้ง |
| `package.json` | สำหรับ `npm start` (ไม่มีแพ็กเกจที่ต้องติดตั้ง) |

## เริ่มใช้งาน
ต้องมี Node.js 18 ขึ้นไป

```bash
cp .env.example .env     # แล้วแก้ SECRET ให้เป็นข้อความสุ่มยาวๆ
node server.js           # หรือ npm start
```
เปิด `http://localhost:3000` เกมจะตรวจเจอเซิร์ฟเวอร์เองและเปิดล็อกอินกับห้องออนไลน์ให้อัตโนมัติ
ถ้าเปิดไฟล์ `tan-set-thi.html` ตรงๆ (ไม่ผ่านเซิร์ฟเวอร์) จะเล่นได้เฉพาะโหมดเครื่องเดียว ไม่มีออนไลน์

## ขึ้นระบบจริง
- **ใช้ HTTPS เสมอ** (ผ่าน nginx, Caddy หรือผู้ให้บริการโฮสต์ของคุณ) และตั้ง `TRUST_PROXY=1` ใน `.env`
- ตัวอย่าง nginx (สำคัญ: ต้องปิด buffering ที่ `/api/` ไม่เช่นนั้นการอัปเดตเรียลไทม์จะช้าหรือค้าง)
```nginx
location / {
  proxy_pass http://127.0.0.1:3000;
  proxy_set_header Host $host;
  proxy_set_header X-Forwarded-For $remote_addr;
}
location /api/ {
  proxy_pass http://127.0.0.1:3000;
  proxy_http_version 1.1;
  proxy_set_header Connection "";
  proxy_set_header X-Forwarded-For $remote_addr;
  proxy_buffering off;
  proxy_read_timeout 1h;
}
```
- รันให้ค้างด้วย systemd หรือ pm2 และตั้งค่า `SECRET` ให้คงที่ (ไม่เช่นนั้นผู้ใช้จะหลุดล็อกอินทุกครั้งที่รีสตาร์ท)
- ข้อมูลผู้ใช้อยู่ในไฟล์ `users.json` ข้างๆ `server.js` **สำรองไฟล์นี้เป็นประจำ** ส่วนห้องเล่นเก็บในหน่วยความจำและหายเมื่อรีสตาร์ท

## เข้าสู่ระบบผ่านระบบภายนอก (เช่น 500 Windows Thailand)
รองรับมาตรฐาน OAuth2 / OpenID Connect ถ้าผู้ให้บริการของคุณรองรับ:
1. ลงทะเบียนเกมกับผู้ให้บริการ ระบุ Redirect URI เป็น `https://โดเมนเกมของคุณ/auth/sso/callback`
2. ตั้งค่าใน `.env`: `PUBLIC_URL`, `SSO_CLIENT_ID`, `SSO_CLIENT_SECRET` และ `SSO_ISSUER` (หรือ `SSO_AUTH_URL` + `SSO_TOKEN_URL` + `SSO_USERINFO_URL`)
3. รีสตาร์ท ปุ่ม "เข้าสู่ระบบด้วย …" จะขึ้นที่หน้าล็อกอินเอง (ถ้าไม่ตั้งค่า ปุ่มจะไม่แสดง)

ถ้าระบบของคุณใช้วิธีอื่น (SAML, API แบบกำหนดเอง ฯลฯ) ต้องปรับโค้ดส่วน `/auth/sso/*` ใน `server.js`

## ปรับแต่ง
แก้ที่ต้นสคริปต์ใน `tan-set-thi.html` (ค้นหาชื่อค่าด้านล่าง)
- `POWERED` ชื่อแบรนด์ท้ายหน้าแรกและหน้าล็อกอิน ("Powered by …")
- `CONTACT` ช่องทางติดต่อผู้ดูแลระบบ (แสดงในหน้าข้อมูลความเป็นส่วนตัวและหน้า "ลืมรหัสผ่าน")
- `CFG` ค่าสมดุลเกม เช่น เงินเริ่มต้น เงินเดือน ค่าครองชีพ อัตราค่าเช่า
- `REG` ข้อมูล 6 จังหวัด (ชื่อช่อง ข้อความความรู้ การ์ดเหตุการณ์ เป้าหมาย)

## ข้อควรระวัง
- **กติกาเกมคำนวณในเครื่องผู้เล่น** เซิร์ฟเวอร์เป็นตัวกลางส่งต่อสถานะ เหมาะกับการเล่นกับเพื่อน ถ้าจะเปิดแข่งขันสาธารณะต้องย้ายการตรวจกติกามาไว้ฝั่งเซิร์ฟเวอร์เพื่อกันโกง
- **ล็อกอินด้วยอีเมล:** เบราว์เซอร์แปลงอีเมลเป็นรหัสย่อก่อนส่ง เซิร์ฟเวอร์ไม่เห็นอีเมลจริง จึงไม่มีระบบส่งอีเมลรีเซ็ตรหัสผ่าน ผู้ใช้ที่ลืมรหัสผ่านต้องติดต่อผู้ดูแลระบบหรือสมัครใหม่
- เนื้อหาความรู้ของ 6 จังหวัดเขียนจากความรู้ทั่วไป ควรให้ผู้รู้ตรวจทานก่อนใช้สอนจริง
- หน้า "ข้อมูลความเป็นส่วนตัว" ในเกมอธิบายการทำงานของโค้ด **ไม่ใช่เอกสารทางกฎหมาย** ถ้าเก็บข้อมูลผู้ใช้จริงควรให้ผู้เชี่ยวชาญตรวจเทียบ พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล (PDPA) และแก้ข้อความให้ตรงเมื่อเปลี่ยนวิธีเก็บข้อมูล
- ฟอนต์โหลดจาก Google Fonts (เบราว์เซอร์ผู้ใช้จึงติดต่อ Google) ถ้าไม่ต้องการ ให้โหลดฟอนต์ Prompt/Sarabun มาไว้ในเซิร์ฟเวอร์เอง แล้วแก้ข้อความในหัวข้อ "บริการภายนอก"
- ระบบนี้เหมาะกับผู้ใช้จำนวนน้อยถึงปานกลาง ข้อมูลผู้ใช้เก็บเป็นไฟล์ JSON เดียว ถ้ามีผู้ใช้จำนวนมากควรย้ายไปใช้ฐานข้อมูลจริง
