# ตอบผิดคือชนะ – ชุดเซิร์ฟเวอร์ของตัวเอง (ห้องออนไลน์โดยไม่ต้องใช้ Claude)

ชุดนี้ทำให้ผู้เล่น **เล่นออนไลน์ด้วยกันผ่านลิงก์เว็บธรรมดา** ไม่ต้องมีบัญชี claude.ai
เซิร์ฟเวอร์ทำหน้าที่แค่เสิร์ฟหน้าเกมและส่งต่อสถานะผู้เล่น/อีโมจิในห้องเดียวกัน
ไม่เก็บข้อมูลลงดิสก์ ห้องอยู่ในหน่วยความจำและหายเมื่อทุกคนออก

## มีอะไรในชุดนี้
| ไฟล์ | หน้าที่ |
|---|---|
| `server.js` | เซิร์ฟเวอร์ (Node.js) เสิร์ฟเกม + WebSocket ที่ `/ws` |
| `public/index.html` | หน้าเกมที่สร้างเสร็จแล้ว (รวมตัวแทนห้องออนไลน์) |
| `game-source.html` + `shim.js` + `build.py` | ต้นฉบับเกมและตัวสร้าง `public/index.html` (ใช้ตอนอัปเดตเกม) |
| `package.json`, `package-lock.json` | รายการแพ็กเกจ (ใช้แค่ `ws`) |

## เริ่มใช้บนเครื่องตัวเอง
ต้องมี Node.js 18 ขึ้นไป
```bash
npm install
npm start          # เปิดที่ http://localhost:3000
```
ทดลองเล่นหลายคน: เปิด `http://localhost:3000` สองสามหน้าต่าง (หรือหลายเครื่องในวงเดียวกันผ่าน IP เครื่องนี้)
กด "ชวนเพื่อน" → "สร้างห้องใหม่" แล้วให้อีกหน้าต่างใส่รหัสห้อง

## นำขึ้นอินเทอร์เน็ตให้เพื่อนเข้าได้
ต้องเป็นบริการที่ **รัน Node.js ค้างไว้ได้และรองรับ WebSocket** และต้องมี **HTTPS**
(เกมใช้ระบบเข้ารหัสรหัสผ่านและกล้องของเบราว์เซอร์ ซึ่งเบราว์เซอร์อนุญาตเฉพาะบน HTTPS หรือ localhost)

ตัวอย่างบริการที่ใช้ได้ (ผมยังไม่ได้ลองขึ้นจริงบนบริการเหล่านี้ ตรวจรายละเอียดกับเอกสารของผู้ให้บริการ):
- **Render / Railway / Fly.io**: เชื่อมโฟลเดอร์นี้ (หรือ repo ที่อัปโหลดไว้) ตั้ง Build = `npm install`, Start = `npm start`
  ระบบจะกำหนดตัวแปร `PORT` ให้เอง
- **VPS ของตัวเอง**: รัน `npm start` ด้วย pm2/systemd แล้วใช้ Nginx หรือ Caddy ทำ HTTPS ชี้มาที่พอร์ตนี้
  (ถ้าใช้ Nginx ต้องส่งต่อ WebSocket: `proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection "upgrade";`)
- แพ็กเกจฟรีของหลายเจ้าจะ "หลับ" เมื่อไม่มีคนใช้ ห้องที่เปิดอยู่จะหายถ้าเซิร์ฟเวอร์รีสตาร์ท
- ตั้งโดเมนย่อยได้ เช่น `game.500windowsthailand.com`

## ตัวแปรที่ปรับได้
| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | 3000 | พอร์ตที่เปิด |
| `MAX_PEERS` | 12 | ผู้เล่นสูงสุดต่อห้อง |
| `MAX_ROOMS` | 500 | จำนวนห้องสูงสุดพร้อมกัน |
| `ALLOWED_ORIGINS` | (ว่าง = ไม่จำกัด) | รายชื่อโดเมนที่อนุญาตให้ต่อ WebSocket คั่นด้วยจุลภาค เช่น `https://game.example.com` แนะนำให้ตั้งตอนใช้งานจริง |

## ความปลอดภัยที่ทำไว้แล้ว
- ตรวจชื่อห้องแบบเข้มงวด (`waw-` + ตัวพิมพ์เล็ก/เลข 3-8 ตัว), จำกัดขนาดข้อความ 8 KB และขนาดสถานะผู้เล่น 4 KB
- จำกัดอัตราส่งประมาณ 30 ข้อความ/วินาที ผู้ที่ส่งถี่ผิดปกติต่อเนื่องจะถูกตัดการเชื่อมต่อ
- ส่งต่อเฉพาะอีโมจิรูปแบบที่กำหนด (เลข 0-5) ข้อมูลอื่นถูกทิ้ง ไม่มีแชตข้อความอิสระ
- ตัดผู้ใช้ที่ไม่ตอบสนองอัตโนมัติ, จำกัดจำนวนห้องและจำนวนคนต่อห้อง
- ส่วนหัวความปลอดภัย (CSP ฯลฯ) ในทุกคำตอบ

## ข้อจำกัดที่ต้องรู้
- **ผู้เล่นไม่ต้องล็อกอินก็เข้าห้องได้** (ใช้ชื่อเล่นที่ตั้งเอง) ใครมีรหัสห้องก็เข้าได้ ชื่อเล่นไม่ได้ผ่านการพิสูจน์ตัวตน
- **บัญชีผู้เล่น (อีเมล/รหัสผ่าน) ยังเก็บในเบราว์เซอร์ของแต่ละเครื่อง** ไม่ข้ามเครื่อง และยังไม่มีระบบกู้รหัสผ่าน
  ถ้าต้องการบัญชีกลางจริง ต้องเพิ่มฐานข้อมูลและระบบยืนยันตัวตนฝั่งเซิร์ฟเวอร์ (ยังไม่ได้ทำ)
- ยังไม่มีตารางอันดับรวม (เวอร์ชัน Claude ใช้ฐานข้อมูลของแพลตฟอร์ม)
- ผลคะแนนและคำตอบที่ถูกอยู่ในโค้ดฝั่งผู้เล่น ผู้ที่ตั้งใจโกงเปิดดูได้ เหมาะกับเล่นกับเพื่อน ไม่เหมาะกับการแข่งชิงรางวัล
- เซิร์ฟเวอร์เครื่องเดียวรองรับได้ตามกำลังเครื่อง ไม่มีระบบกระจายโหลด

## อัปเดตหน้าเกม
เมื่อมีไฟล์เกมเวอร์ชันใหม่: วางไว้เป็น `game-source.html` แล้วรัน
```bash
python3 build.py   # สร้าง public/index.html ใหม่
```
แล้วรีสตาร์ทเซิร์ฟเวอร์ (หรือไม่ต้อง เพราะเซิร์ฟเวอร์อ่านไฟล์ใหม่ทุกครั้งที่ขอหน้าเว็บ)
