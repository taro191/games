# DEV-HANDOFF — Mitty 90 Day (UI redesign build)

เอกสารส่งมอบสำหรับทีมพัฒนา อ่านไฟล์นี้ก่อน แล้วค่อยดู `DEPLOY.md` และ `README.txt`
Powered by Kapsulep & Co

## 1) สรุปสั้น
- ปรับ UI ทั้งระบบเป็นดีไซน์ใหม่ (การ์ดมุมโค้ง พื้นเหลืองอมส้ม + เทาเข้ม หัวข้อเหลืองสด ปุ่มฟ้า ตัวการ์ตูนเส้นขอบหนา)
- **ไม่ได้แก้ตรรกะเกมและ API ฝั่งเซิร์ฟเวอร์** (`server/server.js` เหมือนไฟล์ต้นฉบับทุกบรรทัด)
- ไฟล์ที่เปลี่ยนมี 2 ไฟล์: `public/landing.html` และ `public/index.html`

## 2) ที่เปลี่ยนใน public/landing.html
- หน้าแรกเป็น onboarding 3 หน้า ปัดซ้ายขวา/กดจุด/ปุ่มลูกศรได้ ปุ่มสุดท้ายไป `/play`
- ไฟล์เดียว ไม่ต้องใช้ไลบรารี ใช้ Google Fonts (Kumbh Sans, Kanit) พร้อมฟอนต์สำรอง
- เปิดไฟล์ตรงจากเครื่อง (`file://`) ปุ่มสุดท้ายจะไป `index.html`

## 3) ที่เปลี่ยนใน public/index.html (ตัวเกม)
- **ธีมใหม่:** เขียนต่อท้ายบล็อก `<style>` (ทับธีมเดิมด้านบน) ตัวแปรสี `--sun --y --b --r --sky --ink`
- **หน้า Login/สมัครสมาชิก:** ฟังก์ชัน `authH()` เขียนใหม่ ใช้ฟังก์ชันเดิม `doAuth('login'|'register')`, `goGuest()`, `location.href='/auth/500w/login'` และตัวแปร `S.af`, `S.aerr`, `S.amode` เหมือนเดิม
- **ออนบอร์ดดิงในเกม:** เขียนใหม่ให้ใช้เลย์เอาต์เดียวกับ Login (เนื้อหา 3 ข้อเหมือนเดิม)
- **ตัวการ์ตูน:** `MS()` (ครึ่งตัว), `MF()` (เต็มตัว), `LXCHAR` (ตัวใหญ่) ตัวเลือก 6 แบบจากอาร์เรย์ `AVC` เดิม เก็บค่าที่ผู้เล่นเลือกใน `S.pf.av` เหมือนเดิม
- **หัวหน้าเกม:** `.hud` + แถบสถานะ `.tag` (จาก `TT()`/`PB()`) รวมเป็นหัวมุมโค้งสีเหลืองอมส้ม
- **หัวหน้าเควสต์/เครื่องมือ:** ฟังก์ชัน `PH()` ห่อองค์ประกอบด้วย DOM หลัง render (เรียกจาก `R()` ที่ถูกแยกเป็น `R()` → `R0()` + `PH()`)
- **ปุ่มออกจากระบบ:** `lgo()` เรียก `logout()` หรือ `leaveGuest()` ตามโหมด วาง 2 จุดเท่านั้น (ไอคอนใน HUD และปุ่มใหญ่ล่างแท็บ "ฉัน" — ไม่มีปุ่มในการ์ดโปรไฟล์) แสดงเสมอแม้ไม่มีบัญชี (โหมดไม่มีบัญชีจะกลับไป `/`)
- **ข้อความเครดิต:** "Powered by Kapsulep & Co" ที่ landing, Login และแท็บ "ฉัน"
- **ข้อควรระวัง:** ฟังก์ชันปรับเฉดสีชื่อ `SHD()` (ไม่ใช่ `SD` เพราะ `SD` เป็นอาร์เรย์ชื่อด่านอยู่แล้ว)

## 4) การทดสอบที่ทำแล้ว
ทดสอบด้วย Chromium จำลอง (Playwright) กับเซิร์ฟเวอร์จริงในเครื่อง:
- [x] หน้าแรก → สมัครสมาชิก (`AUTH_MODE=local`) → เข้าเกม → ออกจากระบบ → เข้าสู่ระบบซ้ำ
- [x] Login ผ่าน 500W ด้วยตัวจำลอง `tools/mock-500w.js` (`AUTH_MODE=both`) ได้เข้าเกมและมีบัญชี
- [x] เล่นเควสต์ 1 จนสำเร็จ: +30 XP, +90 ทุนฝึก (3,500 → 3,590) ขึ้นหน้าต่างสำเร็จพร้อมตัวการ์ตูน
- [x] ข้อมูลคงอยู่หลังรีโหลดหน้าและหลังเข้าสู่ระบบใหม่ (บันทึกฝั่งเซิร์ฟเวอร์)
- [x] ออกจากระบบแล้วเข้า `/play` ต้องล็อกอินใหม่
- [x] หน้าจอ 360x640, 390x844 และคอมพิวเตอร์ ไม่ล้นจอ ปุ่มและช่องกรอกครบ
- [x] ไม่มี JavaScript error ในทุกขั้นตอนข้างต้น (มีแค่คำเตือนโหลดฟอนต์ไม่ได้เพราะที่ทดสอบไม่มีอินเทอร์เน็ต และ 401 ก่อนล็อกอินซึ่งเป็นปกติ)

## 5) ที่ยังไม่ได้ทดสอบ (ขอให้ Dev ตรวจ)
- [ ] Login ผ่าน 500 Windows ของจริง (ต้องใช้ `W500_*` จากทีม 500 Windows) ใช้ตัวจำลองผ่านแล้วเท่านั้น
- [ ] เล่นเควสต์ 2–21 ให้ครบทุกขั้นตอนในเบราว์เซอร์จริง (ใช้ปุ่ม ช่องกรอก และแถบเลื่อนชุดเดียวกัน แต่ไม่ได้เดินครบทุกหน้า)
- [ ] ขั้นทบทวนรอบ / เริ่มใหม่ (เมื่อเครดิตหมด) และพักเกม ดูหน้าจอจริงครบทุกขั้น
- [ ] เบราว์เซอร์จริงบน iPhone Safari และ Android Chrome (ทดสอบแค่ Chromium)
- [ ] ฟอนต์ Kanit/Kumbh Sans จริงจาก Google Fonts (ตัวหนังสือจะแคบกว่าที่เห็นในภาพทดสอบเล็กน้อย)
- [ ] ขึ้น Docker + Caddy HTTPS ตาม `DEPLOY.md` และตั้ง `COOKIE_SECURE=1`

## 6) ข้อสังเกต / งานค้างที่อาจทำต่อ
- ปุ่มออกจากระบบกดแล้วออกทันที ไม่มีหน้าต่างยืนยัน
- ไอคอนอีโมจิในรายการเควสต์และปุ่มด่านยังไม่ได้เปลี่ยนเป็นสไตล์วาดมือ
- ตัวใหญ่ในหน้าแรกสร้างจากโค้ดตัวเดียวกับตัวเล็ก เส้นขอบจึงหนากว่าตัวอื่นเล็กน้อย
- ธีมเดิมยังอยู่ในไฟล์ (ถูกเขียนทับด้วย CSS ท้ายบล็อก) ถ้าต้องการทำความสะอาดควรรวมเป็นชุดเดียว
- ป้าย "ตรวจสอบแล้ว" ของผลลัพธ์ต้องมีแอดมิน ซึ่งยังไม่มีในเวอร์ชันนี้

## 7) ขั้นตอนรับไปใช้
```bash
unzip mitty-90-day-complete.zip && cd mitty-90-day-complete
cp .env.example .env            # แก้ AUTH_MODE / ALLOW_GUEST / W500_*
npm run start:env               # ต้องใช้ Node 20.6 ขึ้นไป เปิด http://localhost:3000
# ขึ้นจริง: ดู DEPLOY.md (docker compose up -d --build)
```
ถ้าอัปเดตจากเวอร์ชันเก่า: แทนที่ `public/index.html` และ `public/landing.html` แล้ว `docker compose up -d --build` ข้อมูลผู้เล่นอยู่ในโวลุ่ม ไม่หาย
